Two articles exploring the potential of deploying System One / decision models on network routers and the opportunities that arise when such capability exists across the entire network path.

## Context

These articles synthesise discussions around System One models (introduced in 2026 by TypeSafe AI with Jev and followed by open alternatives) and their possible application in networking infrastructure — from home routers to the full end-to-end path.

They focus on realistic opportunities in application-aware QoS, intent-based networking, adaptive routing, distributed security and new service models, while acknowledging hardware and architectural limitations.
